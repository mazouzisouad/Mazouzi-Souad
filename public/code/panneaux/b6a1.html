Panneau B6a1 : Stationnement interdit

Que signifie ce panneau ?

Le stationnement est interdit du côté où se trouve le panneau, jusqu’à la prochaine intersection. L’arrêt reste autorisé.

Nom officiel : « Stationnement interdit » (panneau B6a1). Famille : interdiction.

Panneaux d’interdiction

Forme ronde, bordure rouge : ils interdisent ou limitent quelque chose (accès, manœuvre, vitesse, stationnement).
