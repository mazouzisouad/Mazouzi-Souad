Panneau C4a : Vitesse conseillée

Que signifie ce panneau ?

Il indique une vitesse conseillée, ici 70 km/h : ce n’est pas une obligation. Une vitesse maximale obligatoire est indiquée par un panneau rond à bordure rouge.

Nom officiel : « Vitesse conseillée » (panneau C4a). Famille : indication.
